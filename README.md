# Sea Level Predictor

## Project Overview

This project analyzes historical sea level data and predicts future sea level rise using linear regression.

Two prediction models are created:

1. Historical trend prediction (1880–2050)
2. Modern trend prediction (2000–2050)

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- SciPy

---

## Dataset

EPA Sea Level Dataset

Source:
https://datahub.io/core/sea-level-rise

---

## Features

- Scatter plot visualization
- Linear regression prediction
- Trend forecasting
- Historical vs modern comparison

---

## Output

The final graph contains:

- Scatter plot
- Historical best fit line
- Modern best fit line
- Labels and title
